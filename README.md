⚽ Proyecto Intermodular ASIR: Clasificación de Ligas de Fútbol

Objetivo del Proyecto

El proyecto consiste en el desarrollo de una aplicación web completa para la visualización de clasificaciones de ligas de fútbol, combinando información deportiva con una funcionalidad social (registro de usuarios, comentarios y subida de archivos multimedia).

Este proyecto sirve como demostración práctica de las habilidades adquiridas en el ciclo formativo de Administración de Sistemas Informáticos en Red (ASIR), abarcando desarrollo, bases de datos y administración de sistemas.

Estructura del Tablero Kanban

El tablero utiliza un flujo de trabajo ágil con cinco columnas:

IDEAS: Funcionalidades opcionales o a futuro (I.1, I.2, etc.).

TO DO (Por Hacer): Tareas pendientes por iniciar (el Backlog principal).

DOING (En Curso): Tareas en ejecución activa (máximo de 2 a 3 tarjetas simultáneas).

TEST (Pruebas): Tareas terminadas que requieren validación, pruebas unitarias y de integración.

DONE (Hecho): Tareas completamente completadas y validadas.

🛠️ Tecnologías y Entorno

El proyecto se despliega en un entorno de virtualización, utilizando la siguiente pila tecnológica (LAMP stack mejorado):

Sistema Operativo: Ubuntu Server (Máquina Virtual) (ASO)

Servidor Web: Apache 2.4 (SRI)

Lenguaje Backend: PHP 8.x (IAW)

Base de Datos: MySQL/MariaDB (GBD)

Frontend: HTML5, CSS3, JavaScript (IAW)
